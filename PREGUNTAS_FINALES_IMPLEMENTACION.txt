PREGUNTA 3: Filtrar años PASADOS
════════════════════════════════════════════════════════════════════════════════

Según acuerdo: "Solo mostrar años actuales/futuros (no pasados)"

┌─────────────────────────────────────────────────────────────────────────────
│ ¿Cómo determinar si un año es "pasado"?
│ 
│ Opción A: Por fecha de fin
│ └─ if (yearEndDate < today) → es pasado
│ └─ Filtrar: academicYears.filter(y => new Date(y.end_date) >= today)
│ 
│ Opción B: Por status
│ └─ if (status === "closed") → es pasado
│ └─ Filtrar: academicYears.filter(y => y.status !== "closed")

│ Opción C: Mostrar todos (ignorar esta regla)
