✅ REGLA 6.1: AddClassModal hace AMBAS llamadas API

FLUJO IMPLEMENTACIÓN:

1. AddClassModal.handleSubmit() ejecuta:
   
   a) POST /api/classes (crear clase)
      └─ Body: { subjectId, sectionId, academicYearId, classroom, weeksDuration }
      └─ Response: { success, data: { id, ... } }
   
   b) POST /api/classes/{classId}/schedules (crear horarios)
      └─ Body: { schedules: [ { day_of_week, start_time, end_time }, ... ] }
      └─ Response: { success, data: [...] }
   
   c) SI ambos OK → llama onSave(newClass)
   
   d) SI cualquiera FALLA → muestra error, NO llama onSave (modal no cierra)

2. TeacherDashboard.handleAddClass():
   ├─ Recibe newClass (ya guardado en BD)
   ├─ Actualiza UI: setClasses([...classes, newClass])
   ├─ Guarda en localStorage
   └─ Modal cierra

VENTAJAS:
├─ ✅ AddClassModal responsable de guardar lo que recolecta
├─ ✅ Transacción lógica: todo o nada
├─ ✅ "No debe dejar crear clase sin horarios" CUMPLIDO
├─ ✅ Si falla → error en modal, usuario puede corregir
├─ ✅ Mejor UX y separación de responsabilidades

VALIDACIONES:
├─ Mínimo 1 horario requerido (ya existe)
├─ Cada horario: day_of_week (0-6), start_time, end_time
├─ No puede haber 2 horarios el mismo día (backend valida)
├─ end_time > start_time (backend valida)


IMPLEMENTACIÓN EN AddClassModal:
─────────────────────────────────

```typescript
const handleSubmit = async (e: React.FormEvent) => {
  e.preventDefault();
  
  // Validaciones...
  if (!formData.subjectId || !formData.sectionId || !formData.academicYearId) {
    toast.error("Por favor completa los campos básicos");
    return;
  }

  if (formData.schedules.length === 0) {
    toast.error("Por favor agrega al menos un horario");
    return;
  }

  if (!formData.weeksDuration) {
    toast.error("Duración en semanas es requerida");
    return;
  }

  setIsLoading(true);
  try {
    // PASO 1: Crear clase
    const classResponse = await apiClient.classes.createClass({
      subjectId: formData.subjectId,
      sectionId: formData.sectionId,
      academicYearId: formData.academicYearId,
      classroom: formData.classroom || "",
      weeksDuration: parseInt(formData.weeksDuration)
    });

    if (!classResponse.success || !classResponse.data?.id) {
      throw new Error("Error al crear la clase");
    }

    // PASO 2: Crear horarios
    const schedulesResponse = await apiClient.classes.createSchedules(
      classResponse.data.id,
      { schedules: formData.schedules }
    );

    if (!schedulesResponse.success) {
      // ❌ Clase se creó pero horarios fallaron
      toast.error("Clase creada pero error al guardar horarios");
      throw new Error("Error al guardar horarios");
    }

    // ✅ TODO OK - Notificar al padre
    onSave(classResponse.data);
    
    // Reset formulario
    setFormData({
      subjectId: "",
      sectionId: "",
      academicYearId: "",
      classroom: "",
      weeksDuration: "",
      schedules: []
    });
    
    toast.success("Clase y horarios creados exitosamente");
    onClose();

  } catch (error) {
    console.error("Error creando clase:", error);
    toast.error(`Error: ${error instanceof Error ? error.message : "Desconocido"}`);
    // Modal NO cierra, usuario puede corregir
  } finally {
    setIsLoading(false);
  }
};
```
