TABLA SCHEMA (schema.sql línea 65):
════════════════════════════════════════════════════════════════════════════════

```sql
CREATE TABLE academic_years (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    name VARCHAR(100) NOT NULL,
    start_date DATE NOT NULL,
    end_date DATE NOT NULL,
    is_current BOOLEAN DEFAULT false,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);
```

NOTAS:
├─ is_current: BOOLEAN, default = false
├─ Solo UNO puede tener is_current = true
├─ No hay campo "status" (active, closed, etc.)
└─ Usa start_date y end_date para determinar período

```typescript
const getCurrentAcademicYear = (years: any[]) => {
  // Primero: buscar por is_current
  let current = years.find(y => y.is_current === true);
  
  // Si no existe, calcular por fecha
  if (!current) {
    const today = new Date();
    current = years.find(y => {
      const startDate = new Date(y.start_date);
      const endDate = new Date(y.end_date);
      return today >= startDate && today <= endDate;
    });
  }
  
  return current;
};

// Pre-seleccionar
useEffect(() => {
  if (academicYears.length > 0 && !formData.academicYearId) {
    const currentYear = getCurrentAcademicYear(academicYears);
    if (currentYear) {
      setFormData(prev => ({ ...prev, academicYearId: currentYear.id }));
    }
  }
}, [academicYears]);

// Filtrar pasados
const futureYears = academicYears.filter(year => {
  const endDate = new Date(year.end_date);
  return endDate >= new Date();
});
```

RECOMENDACIÓN:
└─ OPCIÓN 2 es más robusta y prepara para edge cases
